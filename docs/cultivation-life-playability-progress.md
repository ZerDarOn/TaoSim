### 切片选择

- 复用天机城及周边、现有真实 NPC、百宝阁/酒楼/宗门场所和已注册材料。
- 目标：通过交易、亲采或委托取得材料，学习基础能力并炼制一件有用物品，再进入可准备、可退出、有持续后果的具名冲突。
- 不新建演示世界，不用临时 NPC 或注入资产冒充正常玩法。

### P0 时确认的主要风险

1. `MapPanel` 挂载仍按旧 `currentNodeId` 将地图位置重置到地标，是 B1 的直接机制根因。
2. `mapStore` localStorage、SavePayload.playerMapState 和 `Character.spatialAddress` 仍可形成多个位置来源；必须明确只有 Character/旅行状态写权威。
3. 创建流程只有一个角色卡入口；P2 必须在同一初始化接缝加入穿越/降生/上帝模式，不能平行生成世界。
4. 交易、论道、炼制和部分场所仍是旧 UI 直写路径，跨实体原子性尚未闭合。
5. 全量事件在 50 年夹具达到约 44–47 万条，存档与查询增长必须在 P4/P7 继续观察。

## 地图补充 M0–M3 与试玩纠偏 R0–R4

状态：M0/M1 与原性能优化保留；旧 M2“地点下钻已完成”的判断作废；R0–R4 已完成定向、浏览器与生产构建验收。对应 [地图观察、语义缩放与旅行响应改进](map-observation-zoom-performance-plan.md)；本节不是主方案 P3，也不把旧动态空间 Phase 0–7 误作新生活阶段完成。

### M0 复现与根因

- 固定夹具：小世界目标约 150 NPC、穿越模式、不预演化、玩家位于天机城 14,4，向相邻非虚空格 13,4 发起连续旅行。
- 旧实现首屏约 1,342 个 SVG 子节点、65 条线、184 个 SVG 文本；地图挂载出现 226ms 和 114ms 长任务。
- 旧实现旅行启动墙钟约 105ms，但 CPU profile 中 planSpatialTravel 仅约 0.4ms；路径规划不是主要卡点。
- 旧实现推进 1 小时约 219ms并产生 162ms 长任务；createGameSnapshot 约 92ms，Vue 深响应式读取/重新代理约 30ms，而引擎分钟推进约 3ms。确认主因是每次推进完整遍历响应式世界快照，SVG 全量投影是首屏次因。
- 大世界 100 年浏览器夹具的生成时间超过一分钟，且第一次脚本硬编码了错误相邻格；未把该次失败数据计入前后对比。现保留可参数化性能探针，日常回归用同种子短前史，长期规模仍引用 P0 的 1500 NPC 十年基线。

### M1 路线和观察设置

- NPC 路线支持“关闭 / 选中与关注 / 全部可知”，默认“选中与关注”；玩家当前行程使用独立青色导航线，不受 NPC 路线开关影响。
- 角色视角的“关注”不会成为远程实时定位：只有当前可感知人物才投影实时路线；上帝模式可以观察当前大陆全部真实行程。
- 人名支持“聚合 / 仅选中 / 可知全部”；密集人物默认聚合，显式展开时才创建姓名节点。
- 首批图层均来自已有权威数据：人物来自 WorldState.npcs，道路来自活动 SpatialLink，灵气/资源来自 nodeSpiritQi 与确定性灵脉地形，势力来自 Faction.territories，危险/异变来自动态空间特征。
- 角色只显示当前感知或已探索范围；上帝全知。图层关闭直接返回空投影数组，不暂停 NPC，也不是 CSS 隐藏。
- 显示偏好随 PlayerMapState 保存；字段可选并有本地归一化，旧存档不需要版本迁移。

### M2 语义缩放与天机城近景

- 2026-09-08 用户试玩确认旧实现只是放大同一张 Region SVG，并未切换地图等级；叠加近景也不可交互。因此旧 M2 完成证据无效，不能继续沿用“缩放至地点级即完成”的表述。
- 区域地图支持光标锚定滚轮/触控板缩放、加减按钮、适配视野、回到人物/观察焦点、拖动平移；缩放范围 65%–300%，相机按大陆节流保存。
- 相机语义尺度仍用于宏观/区域信息密度；真正下钻另由 `focusedSpatialNodeId` 驱动，切换为独立 Settlement 层。观察下钻本身不写人物位置、时间或资产。
- 首个地点级实现把 TIANJI_SETTLEMENT 的 8 个节点、8 条道路、场所父子关系和真实 NPC 数量接入统一 SpatialState；没有创建临时地点、第二套 NPC 或反向写入 SpatialAddress。
- 天机城局部图可选择真实节点、查看在场人数并沿真实连接图移动；人物途中位置按当前段比例绘制。抵达建筑后进入既有 Venue 场景，房间级室内地图仍未实现。
- 当前只有天机城具备完整近景；其他地点放大时明确显示“当前焦点暂无详细地图”，不伪造内容。

### R0–R2 路线、调度与密集人物纠偏

- 修复双向道路反向行进时段方向错误；旅行 ETA 在连续前进时保持为计划锚点，避免 96×15 分钟因重复取整比一次推进一天漂移。
- TravelState 保存分段路线、累计/段内进度、推进锚点和计划代次；旧 v9 字段缺失时可恢复。玩家与 NPC 共用途中位置求值，抵达事实使用真实 ETA。
- 暂停后世界可继续流逝但路程冻结；读档仍保持暂停；只允许暂停态继续。受阻路线不得直接恢复，可折返且不返还时间。
- 唤醒队列改为每次消费当前最早项，避免处理晚检查点期间新加入的早检查点被越过；无关空间 revision 不再中断所有行程。
- Region 人群默认聚合；展开时每格最多 8 个错位标记并显示溢出数，姓名仅显示选中、悬停或关注对象，避免多人同格文字完全重叠。

### M3 响应优化与浏览器回归

- createGameSnapshot 改为先对 Pinia 根状态 toRaw，再走原有 JSON 独立快照边界；没有把 Vue Proxy 直接交给引擎，也没有改为共享可变对象。
