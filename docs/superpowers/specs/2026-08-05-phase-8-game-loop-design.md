# Phase 8 — 游戏主循环整合与闭环 设计规格

> **目标：** 将孤岛式的功能模块串联成完整的"修仙一天"体验闭环，达到真正可上手试玩的最低标准。

---

## 1. 背景与问题诊断

### 1.1 当前状态（Phase 7 完成后）

功能模块齐全（创角 / 世界推进 / 战斗 / 修炼 / 渡劫 / 宗门 / 背包 / 大世界 / NPC / 坊市 / 炼器炼丹 / 品质升品），但存在**五处断裂**：

| # | 断裂点 | 现状 | 后果 |
|---|--------|------|------|
| ① | **玩家不老化** | WorldEngine 只对 NPC 调 `LifecycleManager.checkLifespan`，玩家 age 不随时间推进增长 | 闭关 100 年角色仍是 18 岁，寿命系统形同虚设 |
| ② | **玩家不会死** | LifecycleManager 未接入玩家角色 | 无失败结局，无 Game Over，无重玩驱动力 |
| ③ | **导航残缺** | AppShell 只有 5 个入口（首页/创角/大世界/修炼/战棋），坊市/炼器/背包/升品/NPC 全无链接 | 玩家找不到 60% 的功能 |
| ④ | **路由死链** | WorldPage 有 `/tribulation` 链接但该页面不存在 | 点击 404 |
| ⑤ | **无 HUD 常驻** | HP/灵力/AP/灵石/寿命 只在 WorldPage 局部显示，离开后无法感知状态 | 玩家在子页面操作时不知道自己还剩多少资源 |

### 1.2 核心判断

Phase 7 完成了"品质锻造深度"，但**游戏主循环从未闭合**。玩家当前体验：创角 → 进世界 → 推进时间（无变化）→ 各页面孤立操作 → 永远不会死 → 无目标感。

**Phase 8 = 闭环整合**：让"时间推进 → 角色老化 → 修为增长 → 资源消耗 → 死亡结局"这条主线跑通。

---

## 2. 设计决策

### D1: 玩家时间推进联动（核心）

**决策：** 闭关/推进时间时，玩家角色同步老化 + 修为自然增长。

```
推进 N 个月 →
  ├─ 玩家 lifespan.age += N/12
  ├─ 玩家 cultivation.currentExp += comprehension × N × 0.5（悟性越高修炼越快）
  ├─ 玩家 spiritEnergy 恢复满
  └─ 检查寿命 → 若耗尽则触发死亡
```

**边界：**
- 修为增长系数 0.5 是初始值，保留可调空间
- 不在此阶段引入"闭关走火入火"等复杂事件（留待后续）

### D2: 死亡结局

**决策：** 玩家寿命耗尽 → GameOver 页面 → 可重新开始。

- 金丹及以上：元神出窍（理论上可夺舍，但 MVP 只展示结局文字）
- 金丹以下：残魂消散 / 湮灭
- GameOver 页面显示：一生纪要（境界、寿数、死因），提供"返回首页重新开始"

**不做的：**
- 不做夺舍重生（留待后续 Phase）
- 不做战斗死亡（当前战斗页面是测试性质，非正式死亡来源）

### D3: 导航整合

**决策：** AppShell 顶部导航改为分组下拉式，覆盖全部已实现功能。

```
修仙（大世界 / 修炼）
百艺（炼丹炼器 / 装备升品）
社交（坊市 / 偶遇 / 交易）
行囊（背包）
```

**约束：** 角色未创建时，除"首页/创角"外其余 disabled。

### D4: HUD 常驻状态条

**决策：** AppShell 内嵌一个 StatusBar 组件，常驻显示玩家核心状态。

显示：境界 | HP | 灵力 | AP | 灵石 | 寿命（高亮预警色）

**触发：** 仅在 `playerStore.isCreated === true` 时渲染。

### D5: 行动点消耗（轻量版）

**决策：** 炼丹/炼器/大师锻造/升品/交易各消耗 1 AP，AP 每月恢复。

- character 已有 `monthlyActionPoints` 字段，但从未使用
- 此阶段只做"消耗 + 月度恢复"，不做"AP 不足时禁止"的硬阻断（避免把玩家卡死）
- 若 AP 不足，UI 提示但仍允许操作（MVP 友好优先）

## 3. 风险分析

### 核心不变量
- **角色数据一致性：** 时间推进不得破坏 Character 字段完整性
- **存档兼容：** 现有存档加载后仍可正常推进

### 原子性边界
- 时间推进 + 老化 + 修为增长 + 死亡检查 必须在同一事务内完成
- 若推进过程中寿命耗尽，必须立即终止推进并跳转 GameOver

### 副作用
- 死亡触发后：清空 playerStore、提示存档保留（可读取旧存档继续）

### 信任边界
- 时间推进参数（月数）来自 UI 按钮，需校验 ≤ 1200（100 年上限防误操作）

---

## 4. 验收标准

1. 创角后推进 1200 个月（100 年），角色 age ≈ 118，触发寿命耗尽 → GameOver
2. GameOver 页面显示死因"寿元耗尽"，提供返回首页按钮
3. 导航栏可访问所有 13 个已实现页面
4. HUD 在所有页面（除首页/创角/GameOver）常驻显示
5. 炼丹/炼器各消耗 1 AP，次月恢复
6. 全量测试 + 三项目 tsc 通过
